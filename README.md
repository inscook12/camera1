# 곽인아의 AI 영상클래스-카메라 앵글 수업

수강생을 위한 카메라 앵글 5종, 샷 크기 5종 영상 레퍼런스입니다.

- 분류별 보기와 영상 확대·반복 재생
- 이전·다음 영상 이동 및 전체 화면
- 두 영상 나란히 비교, 함께 재생·멈춤, 추천 비교 조합
- 각 구도의 설명과 생각해 보기 질문
